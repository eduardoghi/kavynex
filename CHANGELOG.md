# Changelog

Working notes for the next release, and nothing else. Published versions are not archived here -
each one's notes live on its [release page](https://github.com/eduardoghi/kavynex/releases), which
is the record, and `git log` is the exhaustive one. Keeping a second copy of both here only created
something to drift.

This file exists for what has **not** shipped yet: somewhere to write a user-facing change down
while it is still fresh, so the release notes are not reconstructed from hundreds of commit subjects
at publish time. On release, this section becomes the release description and is emptied again.
